# Retail Units Sold Forecasting

A machine-learning project exploring weekly retail sales and forecasting units sold by store and product.

## Contents

- `retail-units-sold-forecasting.ipynb` - Jupyter notebook with the analysis and modeling workflow.

## Data

The notebook describes the data fields, including week, store, product, prices, promotional placement, and units sold. It expects source data files to be available at the paths specified in its data-loading cells.

## Getting started

Open the notebook in Jupyter Notebook, JupyterLab, or Google Colab and run the cells in order. Install any Python packages requested by the notebook if they are not already available.# retail-units-sold-forecasting
